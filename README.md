# Python Expense Tracker

A menu-driven expense management application built using Python.

## Features
- Add, view, search, update, and delete expenses
- Categorize expenses
- View daily and monthly reports
- Track monthly budgets
- Export expense reports to CSV
- Store data locally using JSON files

## Technologies Used
- Python
- JSON
- CSV
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone this repository:
   ```bash
   git clone https://github.com/rakshitgupta241204-wq/expense-tracker-python.git
   ```
3. Open the project folder.
4. Run:
   ```bash
   python expense.py
   ```

## Privacy Note
Personal expense data files are stored locally and should not be uploaded to a public repository.
